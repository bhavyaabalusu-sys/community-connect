# Community Connect

Community Connect is a Streamlit-based dashboard that helps NGOs and coordinators efficiently match urgent community needs with available volunteers.  
It integrates Google Sheets for real-time data storage and provides charts, maps, and automated matching.

## Features
- Role-based login (Coordinator / Volunteer)
- Dashboard with urgent needs and metrics
- Volunteer profiles with skills and availability
- Automated matches with charts and maps
- Secure session management

## Tech Stack
- Streamlit, Python, Pandas
- Google Sheets integration
- Altair & PyDeck for visualization
